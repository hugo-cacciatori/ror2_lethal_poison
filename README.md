# LethalPoison

In vanilla Risk of Rain 2, Acrid's poison can never kill: it stops its victim at 1 HP. With this mod, poison kills monsters and bosses like any other damage. Its damage, duration and how it is applied are unchanged.

- Players, drones, minions and other allies are never killed by poison (for example under Artifact of Chaos friendly fire): they keep the vanilla behaviour.
- Blight and every other damage-over-time effect are unchanged.

## Installation
Install with a Thunderstore-compatible mod manager, or copy the `plugins/LethalPoison` folder of the release zip into `BepInEx/plugins/`. Requires BepInEx, RoR2BepInExPack and HookGenPatcher.

## Multiplayer
Host-side: only the host needs the mod. Other players can join with or without it.

## Configuration
None.
